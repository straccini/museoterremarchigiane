# Museo delle Terre Marchigiane — media

Repository di deposito per i contenuti multimediali del Museo delle Terre Marchigiane (Collezione Straccini, San Lorenzo in Campo), pubblicati con GitHub Pages.

- `diunavolta/` — video **#diunavolta** (Dopocena XXV, 23 giugno 2026): pagina di riproduzione (`index.html`), poster (`poster.jpg`) e file `diunavolta.mp4`.
  URL pubblico: https://straccini.github.io/museoterremarchigiane/diunavolta/

## Pubblicazione (una volta sola)

1. Creare su GitHub il repository pubblico `straccini/museoterremarchigiane` (vuoto, senza README).
2. Caricare il contenuto di questa cartella (upload da browser o `git push`).
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
4. Dopo 1–2 minuti il video risponde all'URL indicato sopra (quello codificato nel QR della proposta didattica).

## Dominio del museo

Quando `www.museoterremarchigiane.it` verrà collegato a questo repository (Settings → Pages → Custom domain, più record CNAME sul DNS), lo stesso contenuto risponderà a `https://www.museoterremarchigiane.it/diunavolta/` e GitHub reindirizzerà automaticamente gli URL `github.io`: i QR già stampati continueranno a funzionare.

## Sostituzione con il master

Il file depositato è la versione compressa WhatsApp (1024×576). Per sostituirla con il master 1920×1080 basta caricare il nuovo file con lo stesso nome `diunavolta/diunavolta.mp4` (limite GitHub: 100 MB per file).
